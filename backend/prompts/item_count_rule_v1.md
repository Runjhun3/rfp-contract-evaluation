MARKS BY NUMBER OF ITEMS
Criterion {{code}} gives marks by HOW MANY qualifying items the bidder shows, not
per item ({{bands}}). For this item decide only whether it qualifies under the
criterion's conditions: set eligible = true and marks = "1" if it qualifies, or
eligible = false and marks = "0" (with its hard fail) if it does not. List every
test you applied in conditions as usual. Software counts the qualifying items and
applies the RFP's bands.
